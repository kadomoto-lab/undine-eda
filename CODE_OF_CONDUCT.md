# Code of conduct

Undine follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, welcome people of every background and level of experience, and
keep discussions about the design and the code. Harassment, insults and personal attacks are not accepted in issues,
pull requests, discussions or any other project space.

To report behaviour that breaks this code, write to the maintainer through the contact on
[their GitHub profile](https://github.com/kadomoto), or report the comment to GitHub. Reports are handled in
confidence.

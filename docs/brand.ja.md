# Undine — ブランドとカラーパレット

**コンセプト。** Undine は静かに作業できる場所です。夕暮れの深い水、落ち着いた 1 つのアクア、水面から差す光。
柔らかな青と白、長く穏やかな線、何も声高に主張しないこと。出発点はロゴです。
深いティールで描いた、アクアの波が入り組んだ U(運河)です。

原則
- **アクセントは 1 つ。** アクア(`#72bfc6`、ロゴの波)だけが「これが Undine / これが有効」を意味する色です。
- **ニュートラルは青緑で、灰色にしない。** 面とテキストの色はすべて水の方に寄せ、UI が 1 つの色の塊に感じられるようにします。
- **光は暖かい。** 選択は水面の陽光(`sel`)、警告は砂の色、危険はコーラルで、赤ではありません。
- **装飾ではなく意味。** ラベンダーは AI / エージェント(月明かり)、氷の色はクロスプローブに限って使います。
- **データは自分の色を保つ。** PDK のレイヤーの色と Xschem のレイヤーは設計分野のデータです。回路図の配色は、このパレットになじむよう和らげるだけにします。

## 書体と形

- **書体。** UI の欧文は *Atkinson Hyperlegible Next*(`--sans`)。I・l・1 と O・0 の字形が違うので、ネット名やインスタンス名
  (`net_l1`、`vbias_I0`)を読み違えません。和文は同じ理由で選んだモリサワの UD 書体 *BIZ UDPGothic* です。バ・パ、ソ・ン、ロ・口を
  形で区別します。どちらも Web フォントなので、OS によらず同じ書体で表示されます。英字と数字は常に Atkinson で表示し、
  縦に並ぶ数字(表、カウンタ、グラフの読み取り値)は `tabular-nums` で桁をそろえます。名前の中の数字には付けないので、`sky130A` に隙間は空きません。コード・座標・値は *JetBrains Mono*(`--mono`)。
  キャンバスの文字も同じトークンを読みます(`web/src/theme.ts` の `SANS()`)。
- **角は 3 段階。** 構造(セクション、リスト、パネル、ログ、グラフ)は角なし。操作部品と浮いている面(ボタン、入力欄、選択、チップ、
  メニュー、ダイアログ、トースト)は `--radius`(4 px)。丸いのは点とカウンタだけ。
- **カードにしない。** 余白と 1 px の罫線でまとめます。主役の 1 か所(セルページの意図など)だけを一段明るい帯(`--bg1`)にします。
  セクションを箱で囲まない、カードを入れ子にしない、1 px より太い色付きの側線を使わない。
- **深さは出どころ(Waterline)。** 人とエージェントが書いたものは水面近くに、生成されたものやロックされたものは深いところ(`--bg0`)
  に置きます。ライブラリブラウザでは自分のライブラリが水面、ロックされた依存ライブラリと PDK がその下です。セルページでは、意図・
  ソースビュー・テストベンチ(上)と、そこから生成されるネットリストと検証(下)の境目に、アクアの線(水面線)を 1 本だけ引きます。
  ページで唯一のアクセントの線で、アニメーションはしません。
- **今どうなっているかを文で言う。** セルページの冒頭には、サーバーが報告する事実(一致しているビュー、古くなったビュー、検証の
  状態)から組み立てた文を置きます。データにないことは書きません。
- **状態は言葉で。** 状態は色付きの文字で表し、ok と注意には描いたチェックと警告のアイコンを付けます(`--i-check`、`--i-warn`)。
  ピルにはしません。注意の要るノートは枠のない色付きの帯にします。

## ロゴ

ファイルは `web/public/brand/` にあります(形状は元の `undine-logo.svg` のまま変えていません):

| ファイル | 用途 |
|---|---|
| `undine-logo.svg` | 明るい背景用のロゴ全体(深いティール + アクア) |
| `undine-logo-dark.svg` | 暗い背景用のロゴ全体(真珠 `#d4ebef` + ラグーン `#5fb4bf`) |
| `undine-mark.svg`、`undine-mark-dark.svg` | 波入りの U のマークだけ(アイコン、アバター) |
| `undine-mono.svg` | 単色(`currentColor`)。印刷、型押し、重ね表示用 |
| `../favicon.svg` | 深い水色の角丸四角の上のマーク |

ロゴの周りには、縦線 1 本分(U の左の線の幅)の余白を取ります。マークだけなら 16 px 未満、ロゴ全体なら高さ 20 px 未満にしないでください。
波の色を変えたり、縦横比を変えたり、明るい面用のロゴを暗い背景に置いたりしないでください。

アプリでは、ロゴは `Logo` コンポーネント(`web/src/Logo.tsx`)で、色は `--logo-body` / `--logo-wave` に従います。パレットは `web/src/styles.css`(`:root`)にあり、
キャンバスのコードは `web/src/theme.ts` を通して読みます。レイアウトのタイルの背景は `server/undine/layouts/layout.py` の `BACKGROUND` です(`--bg` と同じに保ちます)。
描画した一覧は `web/public/brand/palette.html` にあります。

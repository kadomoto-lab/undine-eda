# セル、意図、ビュー

セルが設計の単位です。ライブラリブラウザでセル名をクリックすると、そのセルの **セルのページ** が開きます。名前の横の小さな
`sch` / `sym` / `rtl` / `lay` のボタンは、これまでどおりビューを直接開きます。

セルのページの冒頭には、セル名と、今どうなっているかを述べる文(一致しているビュー、古くなったビュー、検証の状態)があります。
その下に、上から次のものが並びます。

- **このセルがすべきこと**: セルの意図。目標、選好、仕様、背景、メモと、フローの段階ごとに準備ができていること・まだ必要な情報
  (*回答する* でエディタが開きます)、問題。*意図を編集* でエディタ(ポート、電源、項目、メモ、YAML)が開きます。
- **ビュー**: あなたとエージェントが作業する場所。
  - 回路図、シンボル、RTL、レイアウトのソース。それぞれ、ビューの意図の件数と、回路図とまだ合っているか(ピンが回路図のポートと
    違うシンボル、回路図と合わなくなったレイアウトのデバイス)を表示します。ないビューはここから作れます。
  - セルのテストベンチ。このセルを置いて駆動する回路図(電源やシミュレーションのコマンドを持ち、自分のポートを持たないもの)と、
    仕様が名前で指すテストベンチです。それぞれ、最新のシミュレーションと、それが最新かどうか、または *未実行* を表示します。
  - *使用先*: このセルを置いているセル。
- **水面線**(アクアの線)。その下の一段暗い面に、上のビューから生成されるものが並びます。
  - **ネットリスト**: 必要なときに生成します。
  - **検証**: DRC / LVS の結果です。生成元がその後変わっていれば *古い* と表示します([古くなった結果](verification.md#outdated-results) を参照)。

## 意図の 2 つの層

**セルの意図** は、セルが *何を* 満たすかで、ビューには依存しません。各ビューの **ビューの意図** は、そのビューが *どう* 実現するかです。
回路図での入力対のマッチング、レイアウトでのコモンセントロイド配置やピンの辺、テストベンチで測るときの負荷などです。ビューの項目は、
それが応えるセルの項目を指します。

```
セルの意図:          g1 目標  入力オフセットを最小にする
                     s1 仕様  DC ゲイン 60 dB 以上 (tb_ac)
回路図の意図:        c1       M1 / M2 を同じ大きさで大きく      serves g1
レイアウトの意図:    c2       M1 / M2 をコモンセントロイドに    serves g1
テスト tb_ac:        x2       2 pF の負荷で測る                 serves s1
```

各エディタ(回路図、シンボル、RTL、レイアウト)の **Intent** タブには、そのビューの意図(項目の追加と、応えるセルの項目の選択)と、
読み取り専用のセルの意図が並びます。このビューが応えている項目には印が付き、*セルのページで編集* でセルの意図を開けます。
どのセルの項目にも応えていないビューの制約は報告されるので、どの制約にも理由が残ります。ファイルの形式は [設計文書](../design/intent.md) にあります。

# 表示言語

上部バーの右端にある言語メニュー(翻訳アイコンと、今の言語 **EN** / **JA**)を開き、**English** または **日本語** を選びます。
メニューには各言語がその言語自身の名前で並びます。キーボードでも操作でき、矢印キーで移動、Enter で選択、Esc で閉じます。初回はブラウザが優先する対応言語を使い、対応する言語がなければ英語を表示します。
自分で選んだ言語はプロジェクトとは別に、このブラウザに保存します。ブラウザの保存機能が無効でも、そのセッション内では切り替えられます。

切り替えは再読み込みなしで反映されます。開いているセル、表示位置・倍率、選択、送信前のチャット、フォームの入力内容を維持し、ジョブや設計エージェントの作業も継続します。

操作ボタン、ツールチップ、状態表示、通知、構造化された操作の説明を翻訳します。セル名・ネット名・PDK 名、設計内の文字、SPICE 値、単位は元の意味を保ちます。
ユーザーや AI の文章、生ログ、診断詳細は原文で表示します。UI 言語の変更で会話の翻訳を依頼したり、外部 MCP クライアントの言語を変えたりはしません。

古いサーバーや保存済みの記録に英語の診断要約しかない場合は、原文を表示します。

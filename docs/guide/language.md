# Interface language

Open the language menu at the right of the top bar (the translate icon with the current language, **EN** or **JA**) and
choose **English** or **日本語**; each language is listed by its own name. The menu works from the keyboard: the arrow keys
move, Enter chooses, Esc closes. The first visit uses the browser's preferred
supported language, with English as the fallback. Your explicit choice is remembered in this browser, independently of the project.
If browser storage is disabled, switching still works for the current session.

Language changes take effect immediately, without reloading. Open cells, camera positions, selections, unsent chat text and
form inputs stay in place. Jobs and the Agent continue running.

Controls, tooltips, status labels, notifications and structured operation summaries are translated. Cell/net names, PDK names,
design annotations, SPICE values and units keep their original meaning. User/Agent messages, tool logs and diagnostic details
stay in their original language. Changing the UI language does not request a translation of the conversation or change external MCP clients.

Older servers and saved records may provide English-only diagnostic summaries; these remain visible instead of being guessed from text.

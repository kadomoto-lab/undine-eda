# レイアウトエディタ

| キー | | キー | |
|---|---|---|---|
| F | 全体表示 | Shift+F / Ctrl+F | 全階層 / 最上位だけ |
| R | 矩形 | P / Shift+P | パス / ポリゴン |
| L | ラベル | I | インスタンスを配置 |
| M / C | 移動 / コピー | K / Shift+K | ルーラー / ルーラーを消す |
| Ctrl+C / Ctrl+V | 選択対象をコピー / 貼り付け | | |
| 左ドラッグ | 範囲選択、選択後は移動 | Shift+左ドラッグ | 範囲選択を追加・解除 |
| U / Shift+U、Ctrl+Z / Ctrl+Shift+Z | Undo / Redo | Ctrl+S | 保存 |
| Del | 削除 | Esc | 取り消し、選択ツールへ |
| Enter / Backspace | 図形を確定 / 最後の点を消す | Z / Shift+Z | 拡大 / 縮小 |
| ホイール | ズーム | 中ボタン・右ボタンのドラッグ、Space+ドラッグ、矢印キー | 表示位置の移動 |

インスタンスをダブルクリックすると、そのセルを開きます。編集はセルの最上位の図形とインスタンスに対して行われます。
Undo / Redo は、いま編集しているセルの操作だけを取り消し・やり直しし、同じライブラリの別のセルの編集には触れません。履歴はサーバーの
操作ログにあるので、再起動しても残ります。PCell のインスタンスはパラメータだけを表示します。

未選択の状態で左ドラッグすると範囲選択になります。選択後はキャンバス上の次の左ドラッグで自動的に **移動** に切り替わり、
選択したグループの移動先をプレビューします。離すと1回の Undo で戻せる移動を確定し、選択ツールに戻ります。Esc でキャンセルします。
空白のクリックで選択を解除でき、Shift+ドラッグなら選択中でも範囲選択を追加・解除できます。読み取り専用では常に範囲選択になります。
Pan のツールバーボタンはありません。表示位置の移動には右・中ボタンのドラッグ、Space+ドラッグ、矢印キーを使えます。
M による移動ツールも使えます。基準点、移動先の順にクリックしてください。

Ctrl+C で選択した図形・インスタンスをコピーし、Ctrl+V でポインター位置にプレビューを表示します。
クリックで貼り付け、Esc でキャンセルできます。元の図形を移動・削除しても、コピー時点の形状・属性を保持します。
同じプロジェクト・ライブラリ内の別セルや提案版にも貼り付けられます。参照する子セルは貼り付け先にも必要です。
貼り付け全体を1回の Undo で戻せ、インスタンス名の重複は自動で避けます。再度 Ctrl+V を押すと繰り返し貼り付けられます。
macOS では Cmd+C / Cmd+V も使えます。文字入力欄では通常のテキストのコピペが働きます。
ツールバーの複製操作はコピー／貼り付けに統一しています。C キーによる複製も、専用ボタンなしで引き続き使えます。

## グリッドとペイン

ステータスバーのグリッド欄でスナップのグリッド(µm)を設定します。描画ツールはスナップした位置に十字線を表示し、新しいグリッドはすぐに有効になります。
ライブラリブラウザ、エディタ、その横のパネルの間には境目があり、ドラッグで幅を変え、ダブルクリックで元に戻せます(幅はブラウザごとに記憶されます)。
多くのセルを開くとタブの列はスクロールし、左右に隠れているタブの数を表示します。

## 回路図駆動レイアウト

レイアウトの横のパネルで、回路図のデバイスを PDK の PCell として生成します(**Generate** はないものを配置し、**Sync** はパラメータが変わったものを
その場で差し替えます)。まだ配線していないネットはラッツネストで表示します。回路図の MOSFET の `W` は `nf` 本のフィンガーの合計幅で、`mult` は
並列のデバイス数です。そのため、1 つのデバイスを、1 フィンガーあたり `W / nf`、`nf × mult` 本のフィンガーを持つ 1 つの PCell にします。
そのフィンガーは 1 つのトランジスタとしてつなぎます: ゲートのパッドは met1 の横棒で、ソースとドレインは拡散の上側と下側に沿った met2 の横棒で、
via1 を通してつなぎます(`<pcell>_par` という名前のセルに入ります)。met2 の横棒を 2 本通せないほどフィンガーが短い場合は、配線に任せ、警告を出します。
結果は LVS で `W`、`m = mult` と一致し、DRC 違反もありません。MIM コンデンサ(`cap_mim_m3_1`、`cap_mim_m3_2`)も生成できます。

**ユニット。** MIM コンデンサの `MF`(と `m`)、抵抗の `m` は、レイアウトではその数のデバイスです。Undine は 1 つのデバイスのユニットを
その数だけ、回路図インスタンスに結び付けた 1 つのアレイとして置きます。配線すると、KLayout の LVS は並列のユニットを 1 つのデバイスに
まとめます。アレイのピッチは PDK のルールに従います。Magic が KLayout のデッキより厳しいところは Magic に合わせます:

- sky130 の 1.17 µm の MIM ユニットは 4.17 × 2.71 µm 間隔で置きます。capm から隣のユニットの metal3 まで 1.34 µm です(Magic の capm.11)。
- 下部電極(capm + 0.14 µm)どうしは 1.2 µm 離します(capm.2b)。

PDK のジェネレータは MIM の辺を 2 µm より小さく描きません。Undine は `cap_mim_m3_1` をルールの 1 µm(capm.1)まで描くので、CDAC の
1.17 µm のユニットが黙って大きくなることはありません。PDK の PCell で `MF` を繰り返せないデバイスは、理由とともに表示します(`notes`)。
落としはしません。

**タップ。** MOSFET には、ソース / ドレインのどちらかがバルクのネットにあるときだけ、PCell の突き合わせのバルクタイを付けます。
そのソース / ドレインは li1 でタップにつなぎます(デバイスのセルは `<pcell>_tie`)。突き合わせた接合の上のシリサイドが 2 つをつなぐので、
ほかのネットをそこへ配線すると、シリコンでのショートではなく LVS のエラーになります。どちらもバルクのネットにない
デバイス(サンプリングスイッチの `vin` / `vout` など)にはガードリングを付けます。厚膜酸化膜のタイ(`*_g5v0d10v5`、`*_05v0`)は
コンタクト 2 列分の幅(nfet で 0.99 µm、pfet で 0.86 µm)にします。Magic の diff/tap.16 が 0.7 µm 以上を求めるためです。

**レイアウトパラメータ。** デバイスごとのレイアウト上の選択は、回路図ではなくそのレイアウトインスタンスに保存するので、次の同期でも
保たれます。MOSFET では次のとおりです:

- `nf`: 描くフィンガー数。1 本の幅は W × mult / nf です。回路図は自分の `nf` のままです。sky130 のモデルは合計の W でビンを選び、
  LVS はフィンガーをその W にまとめます。
- `bulk`: auto、tie、ring、none
- `tap_side`: right か left
- `gate`: ゲートのコンタクトの位置
- `sd_contacts`: ソース / ドレインあたりのコンタクトの列数

ユニットのアレイは `columns` を受け付けます。アシスタントは `sync_layout(layout=...)` で設定します。同期が置き換えるデバイス
(パラメータやユニット数が変わったもの)は、位置と向きを保ちます。ユニットのアレイのステップもいっしょに回ります。`place_pcell` や
`place_array` で置いたデバイスは、1 片だけでも設計者のものなので、同期はそのままにします。

同期が別の PCell バリアントに差し替えたデバイス(`nf` が違う、ゲートが反対側にあるなど)は、古いバリアントをライブラリに残します。
あとで消した `place_pcell` の部品も同じです。どこにも置かれていないこれらのセルは検査しません(バリアント単独では設計ではなく、
Magic の LU.2 で落ちるため)。アシスタントの `delete_unused_cells` が changeset から取り除き、戻せば元に戻るように記録します。
対象は、どこにも置かれていない生成セルだけで、既定ではその changeset 自身が作ったものに限ります(ベースラインのものは数を示し、
求められたときに取り除きます)。もういらない試作のセルのような設計者のセルは `delete_cell` で消します。どこかに置かれている間は断ります。

**GF180MCU と IHP SG13G2。** MOSFET は、それぞれの PDK の PCell から同じように生成します:

| | デバイス | 幅 | フィンガーのつなぎ方 |
|---|---|---|---|
| GF180MCU | `nfet_*` / `pfet_*`(3.3、5、6 V)、`nfet_06v0_nvt` | `W` は `nf` 本のフィンガーの合計 | ゲート: ゲートパッドの上の metal1 バー。ソースとドレイン: metal2 |
| SG13G2 | `sg13_lv_*` / `sg13_hv_*` | `w` は `ng` 本のゲートの合計 | ゲート: 拡散層の下のポリのバー(metal1 のパッドにコンタクト)。ソースとドレイン: metal2 |

どちらも `m` はフィンガーを増やして表し、タップ(GF180MCU はバルクタイ、SG13G2 はガードリング)を付けるので、DRC 違反がなく、
バルクも配線できます。SG13G2 の PCell はゲートのコンタクトを描かないので、Undine が付けます(ゲートが 1 本のデバイスにも付けます)。
ゲートもほかの端子と同じく metal1 で配線でき、ラベルも付けられます。

抵抗と MIM 容量も、`W` / `L` のとおりに生成します:

- GF180MCU: `ppolyf_u`、`npolyf_u`、`nplus_u`、`pplus_u`、`nwell`、`rm1`〜`rm3`、`cap_mim_2f0fF`(Metal5 の下の MIM オプション B)
- SG13G2: `rppd`、`rsil`、`rhigh`、`cap_cmim`(値は寸法から計算)

ほかのデバイスと、`m` が 2 以上の GF180MCU / SG13G2 の受動素子は、理由とともに未対応として表示されるので、PCell パネルから
置いてください。LVS では、GF180MCU の抵抗と
MIM のシンボル(モデルの呼び出しとして書かれる)を R / C 素子として比べます。

GF180MCU の LVS はフラットで実行し、デバイスのフィンガーをまとめて比べます。このデッキの階層モードでは、サブセルの中にある pfet
(セルに置いた PCell など)が抽出されないためです。

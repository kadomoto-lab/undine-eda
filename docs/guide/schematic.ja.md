# 回路図エディタ

ライブラリ行には左から **新しいセル**、**既存セルをインポート** が並びます。取り込みフォームで
回路図 (`.sch`)、シンボル (`.sym`)、レイアウト (`.gds`、`.oas`、`.oasis`) を選び、サーバー上のファイルパスを指定します。
回路図とシンボルは Xschem 形式に対応し、ファイル名がセル名になります。同名の既存ビューは上書きしません。
この2種類の取り込みは Undo／Redo と提案からの採用に対応しています。参照するシンボルはプロジェクトの
シンボルライブラリに必要です。レイアウトを取り込む前には、未保存のレイアウト編集を保存してください。

| キー | | キー | |
|---|---|---|---|
| F | 全体表示 | W | 配線(端子・配線をクリック、Enter / Esc で終了) |
| I | シンボルを配置(選択画面) | R / X | 回転 / 反転 |
| L | ネットラベルを配置 | | |
| Ctrl+D | 複製 | Del、Backspace | 削除 |
| Ctrl+C / Ctrl+V | 選択対象をコピー / 貼り付け | | |
| 左ドラッグ | 範囲選択、選択後は移動 | M | 移動ツール |
| U / Shift+U、Ctrl+Z / Ctrl+Shift+Z | Undo / Redo | Esc | 取り消し、選択ツールへ |

未選択の状態で左ドラッグすると選択枠を描き、完全に囲まれたデバイス・配線・ネットラベルを選択します。
選択後はキャンバス上の次の左ドラッグで自動的に **移動** に切り替わり、選択したグループと接続済みの配線・ラベルが追従します。
離すと移動を確定して選択ツールに戻り、Esc でキャンセルできます。Shift+ドラッグなら選択中でも範囲選択を追加・解除できます。
空白のクリックで選択を解除します。読み取り専用では常に範囲選択になります。
右・中ボタンのドラッグ、または Space+ドラッグで表示を移動します。M または **移動** を選ぶ明示的な移動操作も引き続き使えます。
選択後、Ctrl+C でコピー、Ctrl+V でポインター位置にプレビューを表示します。
クリックで貼り付け、Esc でキャンセルできます。元の部品を移動・削除しても、コピー時点の形状・属性を保持します。
同じプロジェクト・ライブラリ内の別の回路図セルや提案版にも貼り付けられ、貼り付け全体を1回の Undo で戻せます。
インスタンス名の重複は自動で避け、ネットラベルの名前は維持します。このため同名のラベルは同じネットにつながります。
再度 Ctrl+V を押すと繰り返し貼り付けられます。Ctrl+D による既存の複製操作や、macOS の Cmd+C / Cmd+V も使えます。
ツールバーの複製操作はコピー／貼り付けに統一し、専用の複製ボタンは置いていません。文字入力欄では通常のテキストのコピペが働きます。

ツールバーの **ラベル配置 (L)** を選び、ネット名を入力して端子や配線をクリックするとラベルを配置できます。
配置前はラベルがポインターに追従し、接続位置にスナップします。続けてクリックすると同じ名前で配置でき、
R / X で回転・反転、Esc で終了します。同名のラベルは同じネットにつながります。
配置したラベルを選択すると、**属性** の `lab` で名前を変更できます。配置は1つずつUndoで戻せます。

配線モードでは、端子をクリックして配線を始めます。空白をクリックすると経由点を確定して配線を続け、端子や既存の配線を
クリックすると接続を完了します。グリッドから外れた端子にも、正確な座標でスナップします。接続後も配線ツールは有効で、
次のクリックから別の配線を始められます。Enter または Esc でも現在の配線を終了できます。
破線のプレビューと確定時の配線は同じ直角経路の計算を使い、デバイスの本体を避けます。経由点のクリックで通り道を指定できます。
自動で追加された曲がりを含め、1クリックで確定した区間を1回の Undo で戻せます。

デバイスの移動・回転・反転では、接続済みの端子に配線が追従します。共有する接続点、分岐、ポート、配線ラベルとの接続も維持します。
古い曲がり点や分岐の位置を固定せず、デバイスの移動先に合わせて必要な配線経路を組み直します。
端子に直接付いたネットラベルはデバイスに、配線上のラベルは移動・再配線された経路に追従します。ラベル名は維持し、外部ポートの位置は固定します。
移動ツールでのドラッグ中は移動先のデバイス・配線・ラベルをプレビューし、マウスを離すと確定します。Esc でドラッグを取り消せます。
プレビュー中は設計ファイルや Undo 履歴を変更しません。
デバイスと配線の変更はまとめて1回の Undo で戻せます。複製では元の接続を移動しません。
安全な経路が見つからない場合や、移動によって回路の接続関係が変わる場合は、設計を変更せずエラーを表示します。

T字の分岐は接続され、接続点にドットを表示します。端子や配線の端点がない場所で配線の途中同士が交差しても、接続にはなりません。
経路計算では、意図しない接続点ができないようにします。

セルは、ライブラリの **+**(**New cell**)ボタンで作ります。名前と、作るビュー(回路図、シンボル、レイアウトのいずれか、または複数)を指定します
(既存のセルにビューを追加するときも同じです)。新しいシンボルのピンは、セルの回路図のポートから作られます
(入力は左、出力と入出力は右に、サブサーキットのピン順で並びます)。

回路図の編集は、すぐに `.sch` ファイルに書き込まれます。ツールバーは **Fit → Redo → Undo** の順に並びます。
Ctrl+S で自動保存の案内を表示します。横のパネルには **Props**、
**Netlist**(Undine、Xschem、vlsirtools のいずれかで生成)、**Simulate** があります。Simulate では、回路図自身の `.control` コマンドを使うか、
パネルで .tran / .ac / .dc / .op の解析を設定します。パネルで設定した場合は、その実行に限り回路図の `.control` ブロックの代わりに使われます
(ジョブにその旨が表示されます)。過渡解析と DC の結果はグラフに、AC は振幅 / 位相で、動作点は値の表で表示します。
テストベンチには PDK のモデルが必要です。PDK のコーナーシンボル(`sky130_fd_pr/corner.sym`。コーナーを選べます)か、`.lib` を書いたコードブロックを置きます。
どちらもない場合は typical コーナーを読み込み、ジョブにそのことが表示されます。意図に代役(遅いセルの代わりの動作モデル)を書いた
テストベンチは、その代役で実行し、ジョブに代役を記録します。[代役](verification.md#stand-ins)を参照してください。

## 回路図と netlist

回路図は回路の図面で、回路そのものはセルの **netlist**(`<cell>.netlist.yaml`)です。図面を編集するたびに netlist も更新され、
ネットリスタ・LVS・エージェントは netlist を読みます([設計](../design/netlist.md))。両者の違いは次の形で見えます。

- **未描画の接続**(ネット名付きの破線と、ステータスバーの *未描画の接続 N件*)は、netlist にあってまだ配線がない接続です。
  たとえば道具が作った接続です。シミュレーションと LVS では有効です。ピンへ配線を描くと破線と置き換わります。勝手に配線されることはありません。
- **道具が置いたシンボル**は、あなたの図面の隣の空いている場所に置かれ、描いたものは動きません。そのシンボルを動かす・回す・反転すると、
  あなたのものになります。ステータスバーの *整列* は、道具が置いたシンボルのうち何も描かれていないものだけを置き直します。
- **パラメータで与える電源。** `sky130_stdcells` の標準セルは電源を端子ではなくインスタンスのパラメータ(`VPWR=vdd VGND=vss VPB=vdd VNB=vss`)で
  受け取り、netlist はネット名でつなぎます。回路図の何も載っていないネット(端子・ポート・ラベルがなく、`Vdd vdd 0 1.8` のような
  コードブロックのノードでもない)を指すパラメータ(既定値 `VPWR` のまま、`vdd` の綴り違いなど)は、回路図とネットリストの警告に
  表示します。名前は SPICE と同じく大文字・小文字を区別せずに比べます。

シンボルや配線を動かして変わるのは回路図のファイルだけで、netlist が変わるのは回路が変わったときだけです。

## シンボル編集

セルの **シンボル** ビューで外形と端子を編集できます。回路図の **スケマティックからシンボルを作成** から、既存の端子を使って
初期シンボルを生成し、作成済みなら **シンボルを開く** で移動します。ライブラリの **新しいセル** から単独のシンボルを作る場合は、
初期の外形だけがあり、端子のない状態で始まります。

**P** で端子、**L** で線、**B** で四角形、**T** で文字を配置します。端子は名前と入出力方向を設定してからクリックで配置します。
端子や図形をクリックするとプロパティを編集できます。ドラッグで範囲選択し、選択後のドラッグでまとめて移動、Delete で削除します。
**属性** では端子名・入出力方向・端子順序を変更できます。端子一覧の上下矢印で、図面上の位置を変えずにネットリストの順序を変更できます。
端子順序はシンボルファイルの端子ボックスの並びです。図面上の位置や、読み込んだ `pinnumber` 属性では決まりません。

端子を移動すると、そのシンボルを参照する回路図の配線が追従し、ネットの接続関係を維持します。回転・反転したインスタンスや、
同じプロジェクトの別ライブラリ内にある回路図にも適用します。埋め込みシンボルや、同じファイル名でも別の場所にあるシンボルには影響しません。
開いている回路図も更新されます。接続を維持できない場合や、読み取り専用の回路図を書き換える必要がある場合は、変更全体を適用しません。

シンボルと配線の変更はまとめて1回の Undo / Redo で戻せます。対象になったどのビューからでも操作できます。
その後に対象ビューを編集した場合は、その編集を先に戻してください。後から追加した接続済みインスタンスがある場合も、古いシンボル操作の
Undo / Redo を拒否することがあり、対象の回路図をエラーに表示します。提案の採用・採用後の取り消しでも同じ確認を行い、
競合時に一部のライブラリだけ変更された状態を残しません。

すでに回路図に配置されているシンボルでも、端子順序と入出力方向は変更でき、端子も追加できます。利用側の回路図は端子名で
つながっているので、そのまま変わりません(追加した端子は未接続で始まり、利用側の配線に重なる位置には置けません)。利用側が接続している端子
(描いた配線、または netlist の保留の接続)の削除や名前の変更、シンボルの種類の変更は拒否します。先に利用側の回路図を変更してください。
利用側の netlist はすべて新しい端子で読み直します。編集のときも、その Undo / Redo、提案のチェックポイントへの復元、採用のときも同じです。

編集はすぐ `.sym` に保存され、Undo / Redo で戻せます。提案版の編集は採用するまで作業コピーに保持されます。
依存ライブラリ、提案の変更前ビュー、エージェントが編集中の提案版は読み取り専用です。

## スケマティックとシンボルの整合性

回路図またはシンボルの **整合性** タブで **スケマティックとシンボルを検証** を実行します。端子名・入出力方向・ネットリストの端子順序を比較し、
不足するビュー、名前のない端子、端子名の重複、回路図のポートを判定するために必要なシンボルが見つからない場合も表示します。

LVS と同様に、結果と実行履歴を保存します。実行時に両ビューのソースと端子情報を取り込み、その後の編集で過去の結果を書き換えません。
端子情報が変わると古い結果であることを表示し、再実行できます。図形の移動やコメント追加だけなら、端子情報が変わらない限り結果は有効です。
PDK や外部検証ツールは不要です。この検証はセルのインターフェースを確認します。レイアウトの接続関係との比較には別途 LVS を使います。
